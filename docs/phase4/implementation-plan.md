# PPL-HR Phase 4 Implementation Plan

Last updated: 2026-05-27

## Phase objective

Build recruitment workflows from opening creation to candidate progression and hiring approval.

## In-scope modules

- Job openings
- Referrals
- Candidate tracker
- Interview stages
- Hire requests

## Functional scope

1. Job management:
   - Create role openings
   - Set owners and priorities
   - Track status by stage
2. Candidate operations:
   - Source channels
   - Candidate profile states
   - Interview scheduling and decision notes
3. Hiring controls:
   - Manager review
   - HR approval routing
   - Final offer decision state

## Role behavior

- Employee:
  - Submit referrals.
- Manager:
  - Review candidates and progress interviews.
- Admin/HR:
  - Control hiring pipeline and approvals.

## Deliverables

- Recruitment dashboard (workflow only, no social feed)
- Candidate lifecycle states
- Approval-safe hire request flow
